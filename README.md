# 🎓 Student Grade Tracker

A simple Python project that calculates a student's total grade and determines whether the student has passed or failed.

## 📌 Features

- Enter student name
- Enter quiz grade
- Enter midterm grade
- Enter final exam grade
- Calculate total grade
- Display student information
- Show Pass or Fail status

## 🛠️ Built With

- Python 3

## ▶️ Example

Input:

```text
Enter student name: Sarah
Enter quiz grade: 20
Enter mid grade: 25
Enter final grade: 40
```

Output:

```text
Student Name: Sarah
Total Grade: 85.0
Status: Pass
```

## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/ghadahh2004/Student-Grade-Tracker.git
```

Go to the project folder:

```bash
cd Student-Grade-Tracker
```

Run the program:

```bash
python main.py
```
